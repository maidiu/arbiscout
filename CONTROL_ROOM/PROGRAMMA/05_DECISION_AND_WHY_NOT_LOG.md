# Decisions and WHY-NOT

**D01 (2026-10-31), retained:** Source-free exact-match/fee-and-margin core is the initial engineering route. Draft PR #1 is **unmerged**. Do not redo it without inspecting exact source and tests.

**D02, retained:** Prefer authorized eBay completed-sales data over active listing prices. The public API license contains restrictive arbitrage and price-modeling language; access to a human research UI does not equal programmatic permission.

**D03, retained:** No mandatory ten. Zero reliable opportunities is an honest output.

**D04, revised contractual analysis:** Actual software function affects which API clauses apply. Best Buy product-purchase recommendations may fit sales-connected license language; restrictions on analysis for the benefit of third parties must be interpreted against the actual operator/function, without presuming a large retailer or resale service. Walmart affiliate I/O retains its separate advertising-only grant unless a different use is authorized. Ordinary purchases (including later resale) are not automatically the same as affiliate-link/API resale purchasing. No fictional individual-volume exemption, but no blanket prohibition on small personal purchase research.

**D05, candidate:** Google Merchant API is not an open Google Shopping-search-results API. Licensed third-party aggregators (e.g., SerpApi, DataForSEO) are plausible cross-retailer discovery sources, conditional on cost, coverage, freshness and contract review.

**D06, optional capability:** Imported purchase offers may be indexed with MOQ, delivery price, duties, timing and quality uncertainty. A downstream resale ROI comparison is optional; do not define the index by that future action.

**D07, retained:** Borrow Rawlsing HQ *methods*, not Rawlsing sovereignty, code, scientific adjudication, protected source data or giant ceremonial bureaucracy.

**D08, retained:** Source-free PR #1 and the PROGRAMMA-control branch are independently reviewable. Neither may declare the other integrated.

**D09, USER GOVERNING REVISION (2026-10-31):** ArbiScout is **a general index of internet retailer bargains under purchase conditions informed by historical eBay price patterns**. It is not constituted *for* a named seller, person or resale business. Earlier resale-arbitrage framing is preserved as historical motivation and optional downstream use, not current governing purpose. The changed actual function affects applicability of restrictive license provisions; labels alone do not rewrite a provider's terms.
