## Shopify misconception and portable storefronts
https://www.shopify.com/legal/api-terms explicitly disallows using the Shopify API for systematic automated data collection or building a commerce/product index, outside other specifically allowed scopes; a public `/products.json` on a Shopify merchant is **not** blanket consent. Each merchant may separately grant specific source-data use, subject to platform and other applicable terms. WooCommerce being unauthenticated is similarly **technical openness only**.

- Micro Center, Office Depot, Costco, Sam's Club, Barnes & Noble, REI, Dick's, Tractor Supply, Kohl's, Macy's, Dell Outlet, Lenovo, HP, Samsung, Amazon, AliExpress, Wayfair: robots and exact current auto-use terms **NOT VERIFIED** in this bounded court. All are explicit HOLDs in the route matrix; 25-site survey does not magically create 25 allowed scrapers.
- `robots.txt` does not itself bind an affirmative commercial data-retention or redistribution right. Technical crawl disallow, a site contract, network/merchant access grant, and anti-bot behavior are separate axes.
- No seller/buyer private information, session cookies, network credential, scraping bypass, stealth or direct endpoint product query was used.
- Current use **does not** involve selling later; site terms banning resale-associated acts must not be recast as a generic ban on ArbiScout. Conversely broad restrictions on product-data extraction remain independently relevant.

## Decision standard
A **green** ingestion source requires: documented source API/CSV or site explicitly permissible for this actual use; fee $0 recurring and usable volume; permitted storage/derived historical price comparisons; exact identity/price/stock and high enough unknown-sale coverage; accessible Mac-local routine without login evasion; real 20–50-product benchmark. A single green JSON parser is only ENGINEERING_PARTIAL and cannot create source permission. For every HOLD ask only the indispensable written authorization/field/retention questions—no new sprawling policy workstreams.
