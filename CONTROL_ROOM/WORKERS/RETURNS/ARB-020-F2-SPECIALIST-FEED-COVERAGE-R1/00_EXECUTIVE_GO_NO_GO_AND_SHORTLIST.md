## Four independent gates for each retailer
1. **Cost:** Free affiliate application or undocumented API tariff is not the same as a signed $0 recurring feed license. Woot requires a key, Impact/CJ require publisher/brand enrollment. Awin historically advertises a refundable **$5 one-time publisher deposit**, which is not a monthly provider charge but violates any literally $0 upfront pledge unless waived; no application submitted.
2. **Actual enumerable sale data:** Woot clearly has category-based feed; Meh public single-deal JSON; Adorama/REI/Acme/DICK'S advertise catalog files behind approval. An affiliate relationship alone does not prove that sale/clearance listings are included or retrievable. No named file was downloaded here.
3. **Permission:** None of the leads has issued ArbiScout a documented purpose-specific grant for autonomous comparison against eBay historical sales, storage, reuse and 0–10 linked report publication. Affiliate programs usually govern referrals, not unrestricted raw catalogs. Obtain terms and written exception/clarification first; no unauthorized collection.
4. **Commercial truth:** Exact model/GTIN and quantity, condition, stock, shipping, member/promo access, merchant of record, final all-in purchaser price and dated eBay **actual-paid** history all remain unverified. Woot has explicit `Condition`, `SalePrice`, `IsSoldOut`, but original manufacturer model and universal UPC cannot be presumed present in its response.
