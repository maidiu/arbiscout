## IMPACT — high-quality specialty merchants, individual advertiser permissions remain decisive
**Network technical law:** [Download Product Catalogs as a Partner](https://help.impact.com/partner/what-would-you-like-to-learn-about/platform-features/marketing-content/product-marketplace-and-catalogs/download-product-catalogs-as-a-partner) states catalogs are visible only if you **joined a brand that uploaded catalog(s)**. Joined partner can download advertiser-native and Impact-standard formats, including gzip; FTP and API for larger files/advanced enabled access. [Feed preferences](https://help.impact.com/partner/what-would-you-like-to-learn-about/platform-features/marketing-content/product-marketplace-and-catalogs/set-product-catalog-feed-preferences-as-a-partner) offers CSV/TAB/XML and compressed feeds. [Applying to brands](https://help.impact.com/partner/what-would-you-like-to-learn-about/platform-features/working-with-brands/applying-to-brands/find-and-apply-to-brands) documents conditional advertiser approval and a catalog-availability flag in marketplace; not publicly interrogated here. There is no separately evidenced recurring *publisher* feed download charge in these articles, but individual advertiser onboarding and legal terms are binding.

## CJ — real searchable product feeds, advertiser-level facts
[Official Product Feed Search](https://docs.cj.com/docs/productfeed-api-search) documents `shoppingProductFeeds`/`productFeeds` meta results with `advertiserName`, `productCount`, `feedName`, `lastUpdated` and type; products GraphQL supports title, category, price, click URL and pagination. Publisher companyId and bearer personal access token required; full subscriptions also supported, some registered-application features require additional approval. [CJ support](https://www.cj.com/support) says **publisher signup is FREE**, website URL must be valid; an advertiser's contract and feed ability are independent. Publisher may inspect joined/nonjoined product-feed summaries using authorized account, but that is NOT a public anonymous directory.

## AWIN — powerful publisher product-feed machinery, but no US merchant-feed guarantee
[Publisher guide updated Aug 31 2026](https://help.awin.com/developers/docs/product-feed-publisher-guide-intro): feed lists all advertiser products **as submitted** and includes URLs, discounts, shipping, names, descriptions; price-comparison publishers are explicitly contemplated. Product Feed List Download gives last-update time; recommend fetching only when changed. [Awin publisher registration guide](https://www.awin.com/us/how-to-use-awin/awin-guide-on-how-to-start-affiliate-marketing) describes a refundable **$5 one-time publisher deposit**, not $49 monthly — the $49 plan sometimes quoted concerns other customer roles/products. No registration attempted, current refund/deposit terms must be rechecked.

**Named public merchant profiles** do exist: [Samsung PT](https://ui.awin.com/merchant-profile/21708), [Samsung GR](https://ui.awin.com/merchant-profile/21725), [Reebok UK](https://ui.awin.com/merchant-profile/121516). These prove **specific non-US/geographically different advertiser programs**, not a US feed usable by ArbiScout. A proper US Awin advertiser/merchant-specific feed shortlist cannot be invented from these. Therefore Awin is a **documented general technical alternative, not a first-three named US source**; HOLD for approved advertiser directory evidence and $5 upfront authorization if required.

## Network refusal rules
A named brand with an enrollment page but no feed is **PROGRAM_ONLY**; a network datafeed API with no named accepted merchant is **GENERIC_NETWORK_ONLY**; named feed documentation without joined advertiser permission is **FREE_AFTER_APPROVAL_CANDIDATE**; a public no-key endpoint without purpose-specific rights is **PUBLIC_DISCOVERY_PERMISSION_HOLD**. No rows are admitted to ArbiScout's daily purchase-gap index from these categories until identity, price, stock and *legally obtained actual paid eBay history* separately pass.

## Mechanical Mac path under actual permission
Impact: compressed normalized CSV/TAB/XML via browser-issued partner approved link/FTP/API → Python standard csv/xml + gzip → SQLite with source/merchant/updated timestamps. CJ: joined advertiser's GraphQL product feed API or approved full feed subscription → JSON/CSV → SQLite. Awin: feed list last-update then URL download → SQLite. AvantLink: approved raw merchant feed subscription → CSV/TAB/XML. Woot: authorized key → feed IDs then batch offers → JSON → SQLite. **None** of these steps licenses generic scraping or permits storage beyond publisher-specific retention rules.
