The three **first-contact merchant routes** are Woot direct API, Adorama Impact and REI Impact. Acme Tools and DICK'S Sporting Goods are backups. No claim that any three can be operated today.

## G1: permitted raw producer → reproducible local Mac consumer
**Assumed existing:** macOS, Python 3, standard-library `json`, `csv`, `gzip`, `xml.etree.ElementTree`, `urllib`, `sqlite3`, `hashlib` and `launchd`. No SaaS API provider fees, proxies, CAPTCHA services or paid browser. Network access solely to expressly approved publisher feed paths and merchant verification as permitted. If approved feed requires SFTP/FTP, use macOS system tools or a standard approved free client; no autonomous downloads conducted here.

**Producer 1 — Woot:** authorized `x-api-key` in local private environment/keychain, never GitHub; call `GET /feed/Clearance`, `GET /feed/Tools`, `GET /feed/Electronics` with documented request-rate budget; store returned *IDs*, category, source item URL, title, condition, IsSoldOut, list/sale price range, StartDate/EndDate; retrieve `POST /getoffers` batches <=25 IDs for detailed contents only under approved source terms. Deduplicate OfferId across category feeds and exclude sold-out, mobile-app-only or non-applicable ZIP before display. **Critical**: confirm original GTIN/MPN presence in detailed offers; absent identity → HOLD and manual manufacturer cross-check, not keyword fuzzy-match certification.

**Producer 2 — Adorama:** joined Impact merchant catalog (advertiser-native or Impact Format gzip CSV/TAB/XML), register file timestamp, size/hash, declared last update, exact brand/catalog ID, merchant-of-record and permitted TTL; parse into SQLite via CSV/XML. Detect names, `manufacturer_mpn`, `gtin/upc`, kit contents, full retail price, sale price, coupon vs rebate, condition (NEW vs USED/Open-box separate), URL and availability. Feed fields are **proposed normalized output**, not guaranteed input names: build an evidence mapping table from actual file header before implementing. Reject kit/body/lens mismatches.

**Producer 3 — REI:** repeat same Impact file approach, respecting expressly **daily in-stock** claimed schedule. Compare source brand/department/category to Outlet linkage only **after verifying** Outlet column/target URLs. If Outlet absent, do not claim closeout coverage. Normalize size/color and SKU (manufacturer model not identical to retailer style code), location/stock vs zip and member special prices; if product is member-only, label eligibility and do not report universal purchase offer.

**Portable schema, only actual fields accepted:**
`source_id, rights_version, authorized_scope, source_record_id, raw_sha256, file_observed_at, source_last_updated_at, product_url, original_merchant, brand, manufacturer_mpn, gtin, edition_revision, variant, quantity, bundle_contents, condition, currency, list_price, current_sale_price, required_coupon, member_eligibility, mandatory_shipping, purchaser_tax_basis, verified_total_purchase_price, checkout_zip, stock_status, stock_checked_at, source_price_expiry, reason_codes`.
Preserve UNKNOWN as null; never convert missing UPC/stock/condition into a false positive. Raw rights/TTL and permitted deletion are source-scoped, not universally persistent data warehouse rights. Store only original catalog fields and derived observations expressly licensed for the approved period.

## G2: 20–50 live offer canary for ONE source (not three-source promise)
1. Once a permitted source is active, retrieve one complete category/deal frame at a known US locale/date, store `frame_total_declared` or `FRAME_INCOMPLETE`, source pagination/limit, feed observed timestamp and all row IDs. If Woot returns several categories, deduplicate by OfferId and report number of distinct enumerated offers.
2. **Preregister** sample 20–50 source rows randomly with a deterministic seed across *eligible new/retail conditions*, not handpick biggest MSRP discounts. If source yields fewer, use all and report small n; don't backfill out of another frame. Capture all rejected rows in denominator.
3. Validate identifier truth: exact manufacturer MPN or GTIN and variant, bundled vs single unit, pack size; a title string is insufficient. Capture merchant link and a permitted one-time independent real stock/price purchase-availability check (not pretending a feed's badge is final checkout); shipping, tax, coupon/membership eligibility and condition separate. If source restrictions forbid programmatic checkout tests, manually confirm a consented subset and mark remainder price-unconfirmed.
4. Audit a diverse 10–20 row direct merchant price/availability subset **without purchasing**. Record URL, time, region, item/ship/tax if known, coupon applicability and precise mismatch reason; reject stale/ambiguous/expired out-of-region offers.
5. Only if independently authorized **actual completed eBay paid-price data** exist, manually audit 5–10 matched models through official Seller Hub Product Research or another source with independently proved true accepted Best Offer amounts. Otherwise mark **RETAILER_CANARY_ONLY**, and do not fabricate eBay history, sector winners or positive gaps.
6. Report precision dimensions: exact model verified / sampled; store stock verified / sampled; total-price accuracy / audited; advertised clearance flags and conditional discounts; recurring credits/charges incurred (expect $0 external but log actual); sample selection and duration/operational minutes; percentage unscannable/invalid identifiers, not inferred 1000/day yield.
7. Stop after one source succeeds/fails decisively; require separate source-specific rights for a second retailer. A 20-item convenience sample is a **technical feasibility test**, not a population incidence estimate or causal market study. Do not source inferences from 1-day Woot deals as annual cadence.

## G3: local engineering failure and negative tests (run later in qualified S2)
- Same Woot OfferId in All+Clearance+Tools deduplicates; offers with `IsSoldOut=true`, expired end timestamp or unavailable state are rejected.
- Woot schema condition variants `new/refurbished/open-box` separated; no using new eBay comparables for a refurbished Woot laptop.
- Adorama `Sony body only` vs `body+kit lens+extras` fails exact bundle match unless eBay identical.
- REI jacket size/color/style ID without true variant identity fails SKU match.
- Acme coupon requiring login, one-time discount or free tool/battery bonus is not treated as universal posted item price.
- Missing GTIN/MPN is `IDENTITY_UNPROVED`, not a guessed UPC.
- Shopper region out of stock, pickup-only or mandatory shipping unknown cannot qualify general offer.
- Missing eBay actual paid Best Offer value leads `NO_EBAY_PAID_REFERENCE`, never displayed sold ask.
- Feed URL not permissioned or cached beyond TTL fails rights gate; stop scheduled downloads if contract revoked.
- All deals absent/nonqualifying leads to honest **zero** daily index candidates.
