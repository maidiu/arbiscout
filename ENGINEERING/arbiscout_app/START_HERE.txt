ARBISCOUT — COMPLETE TEST VERSION
================================

0. ONE-CLICK CONTROL ROOM (Mac and Windows)
   Mac:     double-click start_arbiscout.command
   Windows: double-click start_arbiscout.bat
   The browser opens http://127.0.0.1:8800.

   The app has four main locations:
   - CONTROL ROOM: run Best Buy/Dell/LEGO/Meh/Woot/Kroger, watch progress, stop jobs,
     enter the Kroger ZIP for the next run, and open Settings.
   - DEALS: every product from every source. Filter by source, category and
     observation date; sort by % off, savings, price or name; page through
     results; Save individual rows; build a top-N or hand-picked selection.
     Woot variants are grouped by product family with a variant count.
   - RESULTS: capture eBay sold pages and see the sold low/high/mean/median,
     typical range, gap, and whether the retailer is below the eBay low or
     median. Filter by source, category, date, Top 10 positive gaps, waiting
     for a file, or captured evidence.
   - SETTINGS: API keys, Best Buy/Dell/LEGO URLs, Woot feed, Kroger search terms, links
     to the raw generated report files, and Source coverage (54 cases).
     Six sources are implemented locally (Best Buy, Dell, LEGO, Woot, Meh, Kroger);
     the other 48 are explicit HOLD with the exact rights/feed/terms/capture
     blocker. HOLD sources emit no products; no selectors are fabricated.

   Kroger ZIP is entered on the control room home page for each run. It is not
   saved, so you can change it any time.

1. CLI fallback
   Open Terminal in this folder.
   Install: python3 -m pip install -r requirements.txt
   Run the 20-item fictional demo:
   python3 run_test.py --demo --as-of 2026-11-07 --output fresh_demo --open
   Or open DEMO_OUTPUT/index.html (already generated by tested GitHub CI).

2. Live Best Buy scrape
   ./run_live.command
   Uses installed Chrome/Edge, waits for lazy prices, saves loaded pages, and
   does not open individual product pages. It asks for a deals URL (Return for
   Black Friday) and an optional folder of saved eBay sold pages.

3. API sources
   ./run_api.command meh
   ./run_api.command woot      # choose All for volume
   ./run_api.command kroger    # prompts for search terms and ZIP
   ./run_api.command dell      # Dell Top Deals embedded offers
   ./run_api.command lego      # LEGO sale sets
   Each writes its own <source>_live/retailer/products.json.

4. Deals and Results from the CLI
   ./run_catalog.command       # opens Deals
   ./watch_ebay.command ebay_saved --output catalog/selected --keep-selection
                               # opens Results for the selected run
   ./run_selected.command selected.json
                               # process a downloaded selection

5. eBay evidence
   Save completed-listing pages into ebay_saved/ or ~/Downloads. The Results
   page watches both folders, matches pages by their eBay search query, and
   updates automatically. Any filename works, but save as HTML; Safari Web Archive
   (.webarchive) files are not read. The app never fetches eBay itself.

IMPORTANT: Displayed eBay sold prices are provisional, not independently
verified actual-paid historical sale prices. Gaps are gross; fees, shipping
and net margin are excluded. Live automated eBay sold-search is disabled
because eBay's robots.txt disallows /sch/ for automated agents. Historical
prototypes are retained in HISTORICAL_SOURCE_BANK.
