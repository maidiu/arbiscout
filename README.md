# ArbiScout

Evidence-first retail-arbitrage research.

## Development state
This repository is being bootstrapped. The first prototype is developed on `agent/arbiscout-sourcefree-foundation-r1`.

The project aims to help users discover and evaluate retail resale opportunities using **verified completed-sales evidence**, exact product matching, fee-aware calculations, and transparent decision criteria. It is **not** a purchasing bot.

No eBay, retailer, or AI credentials are required for the initial source-free stage. No unauthorized scraping, undocumented eBay endpoints, or fabricated sold-price data should be used.

**Security:** This repository is currently public. Do not commit credentials, session cookies, private sales data, or personal information.

Live integrations will be considered only after verifying access rights, data licensing, and applicable marketplace terms.
